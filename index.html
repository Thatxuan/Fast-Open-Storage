FO资源存储器 · 使用指南

欢迎使用 FO资源存储器！这是一款专为 Minecraft 玩家打造的纯前端资源管理工具。

✨ 核心功能：

  • 聚合搜索：Java 版和国际基岩版的模组、整合包、资源包、光影实时检索。
  • 版本解析：点击选择版本，筛选游戏版本与加载器。
  • 外部下载：唤起手机/电脑浏览器接管。
  • 3D 皮肤：支持动作切换、皮肤导出、LittleSkin 披风导出、本地披风导入。
  • 头像截取：从 3D 模型截头部生成头像，支持自定义用户名。
  • 本地管家：授权文件夹或拖拽文件导入，自动识别 Java / 基岩版。
  • 主题：6 套主题 + 跟随系统，切换丝滑不掉帧。
  • 戳一戳：点左上角图标试试？

* 本提示首次打开自动弹出，可在“设置”重新查看。
